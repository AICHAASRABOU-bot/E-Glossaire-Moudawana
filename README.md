# 📖 E-Glossaire Moudawana | قاموس مدونة الأسرة التفاعلي

تطبيق ويب تفاعلي وبيلغوي مصمم خصيصاً لتنظيم، بحث، وتوثيق المصطلحات القانونية والمفاهيم المرتبطة بـ **مدونة الأسرة المغربية** (ضمن متطلبات البحث والدراسة الأكاديمية لماستر الأسرة والرعاية الاجتماعية).

---

## ✨ المميزات الرئيسية
- **🔍 البحث الفوري الذكي (Live Search):** تصفية وبحث سريع عن المصطلحات والمواد القانونية أثناء الكتابة دون إعادة تحميل الصفحة.
- **📋 النسخ السريع:** زر مخصص بجانب كل مصطلح لنسخ التعريف فوراً واستخدامه في العروض والأبحاث (`PowerPoint` أو `Word`).
- **⚖️ مرجعية قانونية موثوقة:** يضم أهم المواد والمفاهيم (مثل أحكام زواج المغاربة المقيمين في الخارج - المادة 14، أحكام النفقة، وغيرها).

---

## 🛠️ التقنيات المستخدمة
- **HTML5 & CSS3:** لهيكلة وتصميم الواجهات العصرية.
- **JavaScript (ES6):** لتفعيل التفاعل والبحث الديناميكي.
- **Node.js & Lite-Server:** لإدارة وتشغيل بيئة التطوير المحلية.
